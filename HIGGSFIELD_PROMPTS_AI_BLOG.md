# Higgsfield prompts: Live AI Insights photo posts

Generate at 16:9, then export 1600x900 JPG (q82, metadata stripped) and drop each file at
`public/images/ai/blog/{slug}.jpg`, replacing the placeholder at the same name. No frontmatter edit needed.

The four /ai video loops use the prompts in lws-ai-blueprint-handoff.md Section 4; run each raw render
through `scripts/ai-video-transcode.sh <render> <slot>` (slots: ai-hero, ai-services, ai-proof, ai-how).
